# Mobu logo — Afterglow

From the mountains, to the sea. Momo (lilac) above, Bubu (coral) below, on one post-it.

## Files
- `mobu-brand-sheet.png`: the full sheet, ready to share.
- `svg/mobu-mark.svg`: the detailed mark (moon, pearls, day count on the wave, "i was here" on the corner). Use it large: splash screen, About, onboarding.
- `svg/mobu-icon.svg`: the simplified mark for small sizes, with a transparent background.
- `svg/mobu-app-icon.svg` / `mobu-app-icon-rounded.svg`: app icon on Raised #251F29.
- `svg/mobu-adaptive-foreground.svg` + `png/mobu-adaptive-foreground.png` (432 px): Android adaptive icon foreground. Use #251F29 as the background layer.
- `svg/mobu-wordmark.svg`, `svg/mobu-lockup.svg`, `svg/mobu-lockup-on-dark.svg`: the wordmark and the mark + wordmark + tagline.
- `png/`: app icon at 1024 (stores), 512, 192 (web/PWA), 180 (Apple touch), 48, `favicon.png` at 32.

All text is converted to outlines, so no fonts need installing.

## Colours
| Token | Hex | Role |
|---|---|---|
| Ground | #110D13 | app background |
| Raised | #251F29 | icon background |
| Lilac | #C3A6FF | Momo |
| Coral | #FF8F7E | Bubu |
| Gold | #F2C879 | moon & star |
| Cream | #F6EFE9 | wave foam, text |

Fonts: Fraunces SemiBold (wordmark), Fraunces Italic (tagline), DM Sans, Caveat ("i was here").

## Clear space and use
- Keep clear space of at least the height of the moon around the mark.
- Below 64 px use the simplified icon, never the detailed mark.
- Lilac and coral need the dark ground. On light backgrounds use the app icon, not the bare wordmark.

## Day count
The wave reads "DAY 149 OF US · SINCE 31·05·26" (26 Oct 2026, counting 31 May as day 1). It is a still image, so the in-app counter is where the live number belongs.
